# tabumap-site

האתר של TabuMap ב-GitHub Pages: דף נחיתה, מדיניות פרטיות, והאפליקציה עצמה תחת `/app/`.

- **`main`** – דף הנחיתה (`index.html`), מדיניות הפרטיות (`privacy.html`) והאייקון. אפשר לערוך כאן ישירות;
  כל שינוי מתפרסם אוטומטית ל-`gh-pages` (workflow: Publish landing page changes).
- **`gh-pages`** – מה ש-Pages מגיש. נבנה מחדש בערך פעם בחודש מהריפו הפרטי `tabumap-app`
  (האפליקציה ונתוני החלקות). **לא לערוך את הענף הזה ידנית** – הוא נדרס בכל בנייה.

יוזמה פרטית של RabieMan Labs, אינה שירות ממשלתי. נתוני החלקות: המרכז למיפוי ישראל (data.gov.il).
